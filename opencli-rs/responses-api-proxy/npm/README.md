# @openai/opencli-responses-api-proxy

<p align="center"><code>npm i -g @openai/opencli-responses-api-proxy</code> to install <code>opencli-responses-api-proxy</code></p>

This package distributes the prebuilt [OpenCLI Responses API proxy binary](https://github.com/openai/opencli/tree/main/opencli-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/opencli-responses-api-proxy.js --help
```

Refer to [`opencli-rs/responses-api-proxy/README.md`](https://github.com/openai/opencli/blob/main/opencli-rs/responses-api-proxy/README.md) for detailed documentation.
