# Records review

This produces a list of things worth checking, each traced to the note it came
from. It does not produce conclusions. Somebody qualified reads the list and
decides — this exists to make sure nothing in a long file goes unread, not to
shorten their judgement.

## Read in date order, oldest first

The order matters: a value that means nothing on its own means something
after the one before it. Read every note, including the short ones and the
ones that look like duplicates.

Say how many notes you read, and the range of dates they cover. A review of a
file with a gap in it is a different thing from a review of a complete file,
and the reader has to know which they have.

## What to raise

- **Something changed, and nothing says why.** A value, a dose, a status, a
  plan — different in a later note than an earlier one, with no note between
  explaining it.
- **Something was going to happen and there is no record that it did.** A test
  ordered, a follow-up arranged, a referral made, a review scheduled.
- **Two notes disagree.** Quote both and give both dates.
- **Something has not been revisited.** Say when it was last touched and how
  long ago that is.
- **A gap in the record itself.** Missing dates, unsigned notes, a period with
  no entries.

## For every observation

Three parts, always:

1. What you noticed, in one sentence.
2. The note it came from, **by date**, and its author if the note names one.
3. What would settle it — the thing somebody could check.

```
Dose changed from 5mg to 10mg with no note giving a reason.
  Seen: note of 2026-03-14 (5mg), note of 2026-04-02 (10mg).
  Would settle it: any note between those dates, or asking the prescriber.
```

An observation with no citation is not reported. If you cannot say which note
it came from, you do not know it.

## Say what you could not do

At the end, plainly:

- Notes you could not read, and why.
- Dates with no entries.
- Anything the file refers to that is not in it.

## Never

Read this section as absolute. It is the reason this skill can exist at all.

- **Never state a diagnosis**, or name a condition as present, likely, or
  ruled out.
- **Never recommend a treatment**, a medication, a dose, or a change to any of
  them.
- **Never say a course of action is safe**, or unsafe, or urgent.
- **Never say what the record means clinically.** Report what it says and what
  is missing from it.
- **Never fill a gap.** A missing value is reported as missing. It is never
  inferred from surrounding notes, however clear the pattern looks.

Close with one line saying that nothing here is a decision, and that these are
things to check.
