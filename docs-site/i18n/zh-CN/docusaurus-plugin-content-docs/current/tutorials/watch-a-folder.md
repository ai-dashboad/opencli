# 盯一个文件夹,报告变化

**十分钟。** 做完之后,会有个东西按你定的周期给你写一份简报,说这个目录里动了什么 ——
一个项目、一块共享盘、或者某个人老往里放东西的文件夹。

## 1. 把一个对话指向这个文件夹

新开一个对话,用输入框上方的文件夹按钮选目录。

**这件事比看起来重要:agent 可以写一个对话所在目录里的任何地方,目录之外一个字都写不了。**
**选文件夹就是在选爆炸半径。**

## 2. 先让它写一次

```
用 weekly-report 技能处理这个文件夹。
```

`weekly-report` 是内置技能。它会算出变了什么 —— 是仓库就从 git 里算,否则看修改时间 ——
然后写三段:**做完的、在做的、以及需要谁拍板的**。

**最后那一段才是这份报告被读的理由。**

## 3. 排成定时的

**后台运行 → 排一个重复的:**

| 字段 | |
| --- | --- |
| **做什么** | 用 weekly-report 技能处理这个文件夹。存成 `report-<日期>.md`。 |
| **名称** | 周报 |
| **多久一次** | 7 天 |
| **在哪里执行** | 你选的那个文件夹 |

## 4. 确认它会在哪里跑

**如果那个文件夹不在你的工作区里、也不是一个部门,第一次运行会被扣住**而不是启动,
出现在*等你授权*下面。

**这是有意的。** 授权那个目录,或者把任务移进一个部门。

## 5. 读第一份

**立即执行**,然后打开这次运行,输出是产出多少看多少。

如果报告很薄,**说明这个文件夹这周本来就很薄** —— 这个技能被要求用一行说清楚,而不是
凑字数,因为**一份从空白周凑出来的报告,会教会人跳过报告**。

## 如果盯的是别人的文件夹

有两件事值得小心。

**agent 会读它被指向的一切**,而且**读取在任何沙箱模式下都不受限**。一个装着「你不会
发给你的模型服务商」的东西的文件夹,就不该是你指向的那个 —— **除非你的模型跑在自己
机器上,那样什么都不会离开**。

**一个定时任务活得比你的注意力长。** 每周跑一次、跑一年,就是**五十二次你没看过的运行**。
把目录范围收紧。
