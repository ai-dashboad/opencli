# 路线图

**已知的事情,老实地标好类别。** 这里没有任何一条是带日期的承诺 —— 这是个小项目,
**它守不住的日期比没有日期更不值钱**。

## 正在做

**代码签名。** 桌面端没有 Apple 或微软的证书,**这是产品里最扎手的一处**:一个刚下载
好的东西第一次打开就告诉人出问题了,而其实什么都没出。它要按年付费,**这是它还没发生
的唯一原因**。

**provider 目录。** 现在配一个 provider 意味着写一个你得去查的 `base_url`。
**已经验证过四十家了 —— 那份清单应该在应用里**,选一家是一次点击,然后贴密钥。

**把界面的组织方式改对。** 面板是按零件命名的 —— 产物、派发、定时 —— 而不是按活儿。
**其中三个喂的是同一个队列,却被摆成三个平级的东西。**

## 已知的缺口,还没开始

**从右往左的版面。** 阿拉伯语、希伯来语、波斯语今天就能作为翻译文件加进来,而页面仍然
从左往右排。**那要改样式表。**

**流程画布。** Bot、值守、交接**已经构成一张图** —— 它的数据就在磁盘上 —— 而没有任何
地方能看到它。**现在一条链是一行文字。**

**白标。** 品牌是编译进去的。

**一张多于一行的模型兼容表。** **这是任何人都能做的、最有用的贡献**,而且不需要任何许可:
[测一个模型](/reference/checking-a-model),然后开个 PR。

## 明确不做的

**多用户服务。** 网关是单用户设计的。**一个读你文件、在你机器上执行命令的 agent,
不会因为加了账号系统就变成多租户服务** —— 它会变成一个安全模型完全不同的产品。

**托管版本。** **你的数据没有别的地方可去**,除了你自己选的那家模型服务商。

**我们自己的模型。** 这个东西不带模型,对推理从哪来不持立场。**那就是它的意义。**

## 这个列表怎么变

**它是仓库里的一个文件**,有东西动了就改。如果第二段里有你需要、而且你会用的东西,
[说一声](https://github.com/ai-dashboad/opencli/issues) ——
**一个有人在等的缺口,和一个没人问过的缺口,是两回事。**
