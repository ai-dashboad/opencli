# 大家真正会问的问题

## 我的数据会被发到哪里?

**发到你配置的那个接口,不去别处。** 中间没有我们的网关、没有遥测账号、二进制里也
没有内置任何密钥。

如果那个接口就是你自己机器上的模型,**什么都不会离开这台机器**。

## 离线能用吗?

能,配合本地模型。桌面端会检查自己的更新,「模型」面板会拉一份热门模型列表 ——
这两件事在断网时**安静地失败**,而且都不是聊天所必需的。

## 我需要 API 密钥吗?

**本地跑模型不需要。** Ollama、LM Studio、llama.cpp 这些都不用。用在线服务才需要
它自己的密钥,而密钥不会存进配置文件,保存之后也不会再显示出来。

## 我该用哪个模型?

**你机器装得下的那个,但有一条硬要求:它必须会调用工具。** 不会的话,它在这里只能
聊天。

[测一个模型](/reference/checking-a-model)是个五分钟的测试,直接回答这个问题。

## 为什么它不如 Claude Code / Codex?

因为一个量化到能塞进笔记本的 27B 模型,不是 GPT-5。**界面是一样的,推理不是。**

这个项目改变的是**可达性** —— 你手上这个模型能不能这样用 —— 而不是它有多聪明。

## 能用 GPT-5 或者 Claude 吗?

能。像配置任何其他 provider 一样配 OpenAI 或 Anthropic。**产品内部不偏袒任何一家。**

## 对话从哪个目录开始?

`~/.opencli/workspace`,除非它属于某个部门,那样就从那个部门的目录开始。

以前是你的家目录。**现在不是了**,因为沙箱的可写根**就是**工作目录 ——
见[沙箱与审批](/configuration/sandbox-and-approvals)。

## 几个人能共用一个安装吗?

**不能。** 网关是单用户设计的,它自己的源码里就这么写着。每个人跑自己那一份;后面
接一台共享的模型服务器是常见做法。

## 笔记本睡着的时候定时任务会跑吗?

**不会。** 定时任务和值守只在 OpenCLI 开着的时候运行,因为这是个本地 agent 而不是
服务器。必须在机器睡着时触发的东西,属于 `cron`、`launchd` 或任务计划程序。

## 跟 Open WebUI、Jan 有什么区别?

**它们是本地模型的聊天界面**,而且做得很好。**这个是 agent**:它读写你的文件、执行
命令、并且在后台继续干活。是不同的活儿,两个一起用没有任何问题。

## 跟它 fork 自的 Codex 有什么区别?

Codex 是为 OpenAI 的模型做的。**部门、Bot、值守、后台运行、Bot 之间的交接、内置的
那些流程、以及十种界面语言**,都是 fork 这一侧加的;还有相当一部分工作是在处理
「模型小了会坏在哪里」。

## 为什么提示应用已损坏 / 无法验证?

因为安装包没有 Apple 或微软的证书 —— 那要按年付费,这个项目还没花。
[安装](/getting-started/install)那页写了具体点哪里。

## 能改成我自己的品牌名吗?

**还不能。** 品牌是编译进去的。

## 出问题了,去哪看?

[故障排查](/help/troubleshooting),然后是 `~/.opencli/log` 里的日志,
再然后是[提一个 issue](https://github.com/ai-dashboad/opencli/issues)。
