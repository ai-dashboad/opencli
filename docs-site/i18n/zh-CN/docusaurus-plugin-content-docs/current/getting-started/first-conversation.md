# 第一次对话

## 它从哪里开始

新对话在 `~/.opencli/workspace` 开始,除非它属于某个部门 —— 那样就在那个部门的目录里。

**这件事比看起来重要。** agent 的沙箱可以写它工作目录里的任何东西,所以**一个对话打开
在哪个目录,就是它能改动的全部范围**。以前默认是你的家目录,现在不是了,原因在
[沙箱与审批](/configuration/sandbox-and-approvals)。

用输入框上方的文件夹按钮可以换目录。

## 要它做点什么

用普通的句子。它有你的文件、一个 shell,以及你加过的[连接器](/doing-work/connectors):

```
读 invoices.csv，列出所有违反 rules.md 里规则的行
```

```
这个仓库上周有什么变化？
```

```
比较 their-draft.md 和 our-terms.md，列出所有有差异的条款
```

## 改动之前会发生什么

默认情况下,**一条不确定安全的命令在执行前会先给你看**,一次文件写入在落盘前也会先给
你看。逐个批准或拒绝。

三种设置,在**个性化**里:

| | |
| --- | --- |
| **不熟悉的先问** | 所有不是已知安全的命令,都先给你看 |
| **失败了才问** | 命令自己跑,需要更大权限时才来问你 |
| **从不问** | 执行前什么都不显示 |

最后一种是给「你愿意让脚本在里面撒野的目录」用的。详见
[沙箱与审批](/configuration/sandbox-and-approvals)。

## 看它做了什么

**产物**列出这次对话里 agent 编辑过的文件,带 diff。

有一条诚实的限制:**这里只列用 agent 的文件编辑工具做的改动**。它执行的 shell 命令写的
文件 —— heredoc、脚本、`git checkout` —— **不被追踪,不会出现在那里**。

## 当它开始说不清话的时候

一个变长的对话会被总结,好让它继续装得下。你会看到**「正在压缩对话…」**,之后线程会
带着一份摘要继续,替代较早的那些轮次。

如果**压缩帮不上忙** —— 因为长度来自工具描述而不是对话本身 —— 它会**说一次**,而不是
每一轮都再压一遍。

## 下一步

一次对话就是一次对话。想让活儿在你不在的时候发生,
去[建一个部门](/doing-work/departments-and-bots)。
