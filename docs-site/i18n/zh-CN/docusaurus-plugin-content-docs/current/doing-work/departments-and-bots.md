# 部门与 Bot

一次对话就是一次对话。**会反复出现的活儿,需要一个比对话活得更久的东西。**

| | 是什么 | 住在哪 |
| --- | --- | --- |
| **部门** | 一个目录加一份常设说明 | 默认 `~/.opencli/workspace/<名字>` |
| **Bot** | 部门里的一个会话,带一份职责 | 那个部门 |
| **值守** | 自己到点的一份工作 | 一个 Bot |

这些词是从办公室借来的,**是有意的**。部门不是「取了个好名字的文件夹」——
**它是里面的活儿能触及范围的边界**。

## 从一个现成的开始

九个部门带样例数据一起装好 —— 那些文件里**问题是特意埋好的** —— 所以第一次运行会
真的做点什么,而不是解释说没什么可做。

| 部门 | 带什么来 |
| --- | --- |
| 财务 | 拿 `ledger.csv` 和 `statement.csv` 对账;追逾期的款 |
| 客服 | 回复进来的问题;按「真正在问什么」归类 |
| 运营 | 列出所有还没发货的订单,以及各等了多少天 |
| 市场 | 把笔记变成一周的推文;按买过什么给联系人分组 |
| 人事行政 | 拿简历对岗位;从会议记录里揪出决定和负责人 |
| 法务 | 逐条比对对方草案和我方条款,两版都引出来 |
| 研究 | 研究之间在哪里一致、在哪里冲突、以及为什么 |
| 病历 | 记录了什么、医生该看一眼哪里,并引用原文 |
| 研发 | 读一个服务,报出哪里会给出错误的结果 |

**项目 → 或从一个现成的开始。** 它会建好目录、写入样例文件、并把 Bot 招进来。

## 自己建一个

**项目 → 新建**,然后:

- **名字** —— 它叫什么
- **文件夹** —— 不存在会自动创建
- **常设说明** —— 在这里打开的**每一个**对话都会带上它

常设说明是放「你本来每次都要重打一遍」的东西的地方:怎么构建、什么不许碰、哪些数字是
政策。它和上面那段描述是分开的 —— **描述只有你自己读**。

## Bot

一个 Bot 就是一个带职责的会话。**每次唤醒它,那份职责都会重新带上**,所以不用再告诉它
一遍它是干什么的。

**员工**面板里有四种状态:

| | |
| --- | --- |
| **空闲** | 没事做 |
| **工作中** | 有一次运行正在进行 |
| **等你** | 它停下来问你了 —— 见[值守](/doing-work/duties) |
| **出错** | 上一次运行失败了 |

## Bot 之间传活儿

一个 Bot 可以**按名字**把活儿传给另一个,**连同它做了什么、产出了哪些文件**一起传过去。
接手的那个从这些东西开始,而不是从零开始。

有三道拒绝防止它失控,**而这三道就是这个功能的实质**:

- **深度。** 一条链最多八跳。
- **重复。** 同一个 Bot 在一条链里最多出现三次。
- **方向。** 一个 Bot 只能被**被允许的部门**交活儿。同一个部门内部永远允许。

**员工**面板显示每一条链,并且**标出那些「因为跳数用完而停,不是因为干完了」的**。
