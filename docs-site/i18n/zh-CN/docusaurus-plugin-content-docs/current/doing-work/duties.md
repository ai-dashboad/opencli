# 值守

值守是一个 Bot 按周期执行的工作,**并且在碰到不该自己决定的事情时停下来问你**。

**最后那半句才是重点。** 任何东西都能按时跑一段提示词;让它对真实工作有用的,是
**它被事先告知了哪些事情不许它自己拍板**。

## 四个字段

```
做什么        逐行比对 ledger.csv 和 statement.csv，
              列出对不上的，带凭证号和金额。

规则          金额差小于 1.00 算舍入，忽略。

什么时候问你   任何单笔超过 10000。

多久一次       24 小时
```

**「做什么」和「规则」是特意分开的。** 活儿每天都一样,而退款上限是**某个人会回头修订的
政策**。合成一段提示词之后,改那个数字就得重读整段指令才能找到它。

**「什么时候问你」是用话写的,不是一个条件表达式。** 它作为一项**义务**交给模型,不是
由产品去判断 —— 也就是说,**它的可靠程度完全等于读它的那个模型**。所以要写成可核对的:
*任何单笔超过 10000*,而不是*任何异常*。

## 它停下来之后会怎样

**值守停住。** 它带着那个答不了的问题出现在**员工 → 等你答覆**里,而且
**在你回复之前不会再运行**。

你的回答会带进下一次运行,**所以它不会为同一件事问第二遍**。

一个已经问过的值守**不会再提一个新问题** —— 它会重复那个还开着的。

## 它记住什么

值守在两次运行之间**留笔记**。学到一件事的那次运行只写下那一件;它**不必把已经知道的
重述一遍**,而一次跑到一半失败的运行**也不会把其余的笔记带走**。

写一个空值,就是**故意忘掉**某件事。

## 它在哪里运行

在那个 Bot 的部门目录里,**而那就是这次运行能写入的全部范围**。指向别处的值守会被扣住,
等你按名字授权 —— 见[沙箱与审批](/configuration/sandbox-and-approvals)。

## 值守和定时任务

两者都是按时跑一段提示词。**区别在于它属于谁。**

| | 属于 | 会升级 | 会记忆 |
| --- | --- | --- | --- |
| **值守** | 一个部门里的一个 Bot | 会 | 会 |
| **定时任务** | 不属于任何东西 | 不会 | 不会 |

「每天早上九点告诉我有什么变化」用定时任务。**带着政策的活儿用值守。**
