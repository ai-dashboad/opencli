# 连接器

连接器是 agent 用来调用工具的 MCP 服务 —— GitHub、一个数据库、一个浏览器、你的文件。
**它是 agent 够到「不是本机文件」的那些东西的方式。**

## 添加一个

**能力 → 连接器**列出已配置的和可添加的。从目录里加只要一次点击;加自己的需要一个名字,
外加一条命令或一个地址:

| | |
| --- | --- |
| **本机命令** | 这台机器上的一个程序,由 OpenCLI 启动 |
| **HTTP 服务** | 一个通过 HTTP 能到达的服务 |

## 密钥

大多数连接器需要密钥。**填服务需要的环境变量名** —— 只填名字、空格分隔 —— 值随后再设。

**值和你其他的密钥存在一起,不在连接器的配置里**,而且保存之后不会再显示出来。
这是有意的:**配置文件会被分享、会被粘进 issue,里面的密钥会跟着一起走。**

## 测试

**测试连接**会启动每一个已配置的服务并等待握手。它是一个**按钮**,而不是打开面板就自动跑,
因为启动它们要花几秒 —— 对一个认证失败的服务实测是 2.2 秒。

结果显示在每一行上,连同那个服务提供的工具列表。

## 改动什么时候生效

**服务是跟着对话启动的。** 现在加的连接器对**下一个**打开的对话生效,不是眼前这个。

## 连接器不是什么

**它不是模型获得的能力。** 一个不肯调用工具的模型,不会因为加了连接器就开始调用 ——
见[做不到什么](/reference/limits)。

## 部门

列表上方的标签按部门筛选,**所以一个刚建好的财务部可以被问「这个该连什么」,而不是
「Playwright 是什么」**。

**没有打部门标签的连接器在每个标签下都显示** —— 没人给它归过类,不该等于对所有人隐藏。
