# OpenCLI

### 给你自己跑的模型,一个 agent

跑在你自己的电脑上,能用任何 OpenAI 兼容的模型,而且**是去干活,不是描述活儿**:
读你的文件、执行你的命令、修改你的东西,你不在的时候也在后台继续。

</div>

## 装起来

<Tabs groupId="install">
<TabItem value="macos" label="macOS" default>

下载 [`OpenCLI-macos-aarch64.dmg`](https://github.com/ai-dashboad/opencli/releases/latest/download/OpenCLI-macos-aarch64.dmg)
(Apple 芯片)或
[`OpenCLI-macos-x86_64.dmg`](https://github.com/ai-dashboad/opencli/releases/latest/download/OpenCLI-macos-x86_64.dmg)
(Intel),拖进「应用程序」。

安装包没有 Apple 证书,所以第一次打开要多做一步:

```shell
xattr -dr com.apple.quarantine /Applications/OpenCLI.app
```

或者右键点应用、选**打开**。只需要一次。

</TabItem>
<TabItem value="windows" label="Windows">

下载并运行
[`OpenCLI-windows-x86_64-setup.exe`](https://github.com/ai-dashboad/opencli/releases/latest/download/OpenCLI-windows-x86_64-setup.exe)。

因为没有签名,SmartScreen 会弹一个蓝框。点 **More info**,再点 **Run anyway**。

</TabItem>
<TabItem value="linux" label="Linux">

下载
[`OpenCLI-linux-x86_64.AppImage`](https://github.com/ai-dashboad/opencli/releases/latest/download/OpenCLI-linux-x86_64.AppImage),
加执行权限然后运行:

```shell
chmod +x OpenCLI-linux-x86_64.AppImage
./OpenCLI-linux-x86_64.AppImage
```

</TabItem>
<TabItem value="cli" label="终端">

```shell
curl -fsSL https://opencli.ai/install.sh | sh
```

它会判断你的平台、下载对应的构建,把 `opencli` 放进 `/usr/local/bin` —— 没有写权限
就退到 `~/.local/bin`。

</TabItem>
<TabItem value="source" label="从源码">

需要一个较新的 Rust 工具链:

```shell
git clone https://github.com/ai-dashboad/opencli.git
cd opencli/opencli-rs
cargo build --release -p opencli-cli --bin opencli
```

</TabItem>
</Tabs>

**它不带模型。**[指一个给它](/getting-started/point-at-a-model) —— 本机的 Ollama、
你自己的服务器,或者[四十来家供应商](/getting-started/providers)之一,其中不少家
给免费额度。

## 花一晚上之前值得知道的两件事

**小的本地模型干这个不如前沿模型。** 界面是一样的,推理不是。而且**一个不会调用工具的
模型在这里根本干不了活** —— 它只会聊天。投入之前[先测一下](/reference/checking-a-model)。

**agent 的沙箱可以写它工作目录里的任何东西。** 那个目录就是它能改动的全部范围 ——
这也是为什么对话从一个工作区开始,而不是从你的家目录。
