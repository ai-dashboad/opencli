# コネクター

**コネクターとは、エージェントがツールを呼ぶための MCP サーバー**です ——
GitHub、データベース、ブラウザー、あなたのファイル。
**このマシンのファイルではない何かに、エージェントが手を伸ばす方法**です。

## 追加する

**Abilities → Connectors** が、設定済みのものと追加できるものを並べます。
カタログから足すのは一クリック、自分のものを足すには名前と、コマンドか URL のどちらかが要ります:

| | |
| --- | --- |
| **ローカルコマンド** | このマシン上のプログラム。OpenCLI が起動します |
| **HTTP サーバー** | HTTP で届くサーバー |

## 鍵

**ほとんどのコネクターに鍵が要ります。** サーバーが期待する環境変数の**名前だけ**を
空白で区切って挙げ、**値はあとから設定します**。

**値はコネクターの設定ではなく、あなたの他の鍵と一緒に保管され**、
**一度保存したら二度と表示されません**。これは意図的です:
**設定ファイルは共有されたり issue に貼られたりするもので、中にある鍵はそれについていきます。**

## テスト

**Test connections** は設定済みのサーバーをすべて起動し、握手を待ちます。
パネルを開いたときに勝手に走るのではなく**ボタン**なのは、**起動に数秒かかる**からです ——
認証に失敗する一台で **2.2 秒**を実測しました。

結果は各行に、**そのサーバーが提供するツールとともに**表示されます。

## 変更がいつ効くか

**サーバーは対話とともに起動します。** 今足したコネクターは、**目の前の対話ではなく
次に開く対話**に効きます。

## コネクターでないもの

**それはモデルが得る能力ではありません。** ツールを呼ばないモデルは、
**コネクターを足したからといって呼び始めたりしません** ——
[できないこと](/reference/limits)を見てください。

## 部門

一覧の上のチップは部門で絞り込みます。ですから、作ったばかりの経理部門に対して
*これは何につながっているべきか* を訊けます —— *Playwright とは何か* ではなく。

**部門タグのないコネクターはどのチップの下にも出ます**:
**誰も分類していないものを、全員から隠すべきではありません。**
