# 部門とボット

**対話は一つの対話です。** 何度も回ってくる仕事には、**それより長生きするもの**が要ります。

| | 何か | どこにある |
| --- | --- | --- |
| **部門** | ディレクトリ + 常設の指示 | 既定では `~/.opencli/workspace/<名前>` |
| **ボット** | 部門の中にある、仕事を持った対話 | その部門 |
| **当番** | 自分から回ってくる仕事 | ボット |

**言葉はわざとオフィスから借りています。** 部門は「きれいな名前のついたフォルダー」ではなく、
**その中の仕事が触ってよい範囲の境界**です。

## すでに動くものから始める

**九つの部門がサンプルデータつきで同梱されています** —— **あらかじめ問題が仕込まれたファイル**なので、
最初の実行は「やることがありません」と説明する代わりに**実際に何かをします**。

| 部門 | ついてくるもの |
| --- | --- |
| 経理 | `ledger.csv` と `statement.csv` を突き合わせる。期限切れを追う |
| サポート | 届いたものに答える。質問を「本当は何の話か」で束ねる |
| 業務 | まだ出荷していない注文と、どれだけ待たせているかを全部挙げる |
| マーケティング | メモを一週間分の投稿にする。連絡先を購入内容で分ける |
| 人事・総務 | 応募者を職務要件に照らして読む。メモから決定事項と担当者を抜き出す |
| 法務 | 先方の草案と自社の条件を、条項ごとに、双方を引用して比べる |
| リサーチ | 研究が一致するところ、食い違うところ、そしてその理由 |
| 診療記録 | 記録されていること、そして臨床家が見るべきところを引用つきで |
| エンジニアリング | サービスを読み、**誤った答えを返しうる箇所**を報告する |

**Projects → すでに動くものから始める。** ディレクトリを作り、サンプルファイルを書き、
ボットを雇います。

## 自分で作る

**Projects → New**、そして:

- **名前** —— 何と呼ぶか
- **フォルダー** —— なければ作られます
- **常設の指示** —— ここで開く***すべての***対話でエージェントに渡されます

**常設の指示は、そうでなければ毎回打ち直すことを置く場所**です:どう構築するか、
何に触らないか、どの数字が方針か。**あなたしか読まない説明文とは別物**です。

## ボット

**ボットは仕事を持った対話です。** その仕事は**ボットが起こされるたびに毎回入り直す**ので、
何のための存在かを言い直さなくて済みます。

**Bots** パネルでの四つの状態:

| | |
| --- | --- |
| **待機** | やることがない |
| **作業中** | 実行が進んでいる |
| **あなた待ち** | 止まって訊いた —— [当番](/doing-work/duties)を見てください |
| **エラー** | 直前の実行が失敗した |

## ボット同士で仕事を渡す

ボットは**名前を指して**別のボットに仕事を渡せます。**やったこと**と**作ったファイル**を添えて。
受け取った側は、ゼロからではなくそこから始めます。

**三つの拒否**がそれの暴走を止めます。そして**それこそが中身**です:

- **深さ。** 連鎖は**八段まで**。
- **繰り返し。** 一つの連鎖で**同じボットは三回まで**。
- **向き。** ボットは、**許可された部門からしか**仕事を渡されません。同じ部門の中なら常に許可されます。

**Bots** パネルはすべての連鎖を表示し、**終わったからではなく縄が尽きて止まったもの**に印をつけます。
