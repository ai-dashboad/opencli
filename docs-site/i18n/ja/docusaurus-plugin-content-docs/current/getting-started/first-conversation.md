# 最初の対話

## どこで始まるか

新しい対話は `~/.opencli/workspace` で開きます —— その対話が部門に属する場合を除き、
そのときは部門のディレクトリで開きます。

**これは見た目より重要です。** エージェントのサンドボックスは作業ディレクトリの中なら
どこにでも書けるので、**対話がどのディレクトリで開いているかが、変更されうる範囲のすべて**です。
以前はホームディレクトリが既定でしたが、今は違います。理由は
[サンドボックスと承認](/configuration/sandbox-and-approvals)にあります。

入力欄の上のフォルダーボタンで変えられます。

## 何かを頼む

普通の文で構いません。エージェントにはあなたのファイル、シェル、
そしてあなたが足した[コネクター](/doing-work/connectors)があります:

```
invoices.csv を読んで、rules.md の規則に反する行を全部挙げて
```

```
このリポジトリでこの一週間に何が変わった?
```

```
their-draft.md と our-terms.md を比べて、違う条項を全部挙げて
```

## 何かが変わる前に起きること

既定では、**安全と分かっていないコマンドは実行前に見せ**、
**ファイルへの書き込みは行う前に見せます**。一つずつ承認するか拒否します。

**Customize** にある三つの設定:

| | |
| --- | --- |
| **見慣れないものは全部訊く** | 安全と分かっていないコマンドを毎回先に見せる |
| **失敗したときだけ訊く** | コマンドは無人で走り、もっと権限が要るときだけ訊かれる |
| **一切訊かない** | 実行前に何も見せない |

最後のものは、**スクリプトを放しても構わないディレクトリ**向けです。詳しくは
[サンドボックスと承認](/configuration/sandbox-and-approvals)で説明しています。

## 何をしたのかを見る

**Artifacts** は、この対話でエージェントが編集したファイルを差分つきで並べます。
正直な限界が一つ:**ここに載るのはエージェントのファイル編集ツールで行った編集だけ**です。
エージェントが実行したシェルコマンドが書いたファイル —— heredoc、スクリプト、
`git checkout` —— は追跡されず、ここには出てきません。

## 話が入りきらなくなったら

長くなった対話は、**収まり続けるように要約されます**。
**Summarising the conversation…** と出て、そのあとスレッドは古いやり取りの代わりに
要約を置いて続きます。

**要約しても助けにならないとき** —— 長さの出どころが対話ではなくツールのスキーマである場合 ——
**毎回やり直す代わりに、一度だけそう言います。**

## 次

**一つの対話は一つの対話です。** あなたがいなくても仕事が進むようにするには、
[部門を作ってください](/doing-work/departments-and-bots)。
