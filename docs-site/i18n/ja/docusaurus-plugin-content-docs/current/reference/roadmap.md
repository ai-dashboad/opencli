# 見取り図

**分かっていることを、正直な見出しのもとに。** **ここに日付つきの約束は一つもありません** ——
**これは小さなプロジェクトで、守れない日付は日付がないことより値打ちがない**からです。

## いま手をつけているもの

**コード署名。** デスクトップのビルドは Apple や Microsoft の証明書を持っておらず、
**それが製品で一番ざらつく角**です:**落としたばかりのものを初めて開くと、
何も問題がないのに問題があると告げられます**。**年ごとにお金がかかり、
それが実現していない唯一の理由**です。

**供給元のカタログ。** いま供給元を設定するというのは、**自分で調べに行くべき `base_url`
を書くこと**を意味します。**四十社を検証済みです —— その一覧はアプリの中にあるべき**で、
選ぶのは一クリック、あとは鍵を貼るだけになるはずです。

**画面の形を今に合わせる。** パネルは**仕事ではなく部品で名づけられています** ——
artifacts、dispatch、scheduled。**そのうち三つは同じ待ち行列に流し込んでいるのに、
三つの対等なものとして並べられています。**

## 分かっている欠落、まだ着手していないもの

**右から左への版面。** アラビア語、ヘブライ語、ペルシア語は**今日でも翻訳ファイルとして
足せますが、ページは依然として左から右に並びます**。**それはスタイルシートの変更です。**

**流れの画布。** ボット、当番、受け渡しは**すでに一つのグラフをなしています** ——
**そのデータはディスク上にあります** —— **そしてそれを見る手段がどこにもありません**。
**今のところ、一つの連鎖は一行のテキストです。**

**白ラベル化。** ブランドはコンパイル時に埋め込まれています。

**一行より多いモデル互換表。** **これは誰にでもできる、最も役に立つ貢献**であり、
**何の許可も要りません**:[モデルを試して](/reference/checking-a-model)、
プルリクエストを開いてください。

## 意図して予定に入れていないもの

**多利用者向けの提供。** **ゲートウェイは設計として単一利用者**です。
**あなたのファイルを読み、あなたのマシンでコマンドを走らせるエージェントは、
アカウントを足したところで多テナントのサービスにはなりません**。
**まったく別のセキュリティモデルを持つ、別の製品になります。**

**ホスト版。** **あなたが選んだモデルの供給元のほかに、あなたのデータの行き先はありません。**

**自前のモデル。** **これはモデルを同梱せず、推論がどこから来るかについて立場を持ちません。**
**それがこれの意義です。**
