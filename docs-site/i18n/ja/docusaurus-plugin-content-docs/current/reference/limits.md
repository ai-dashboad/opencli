# できないこと

**あとで気づく代わりに、ここで言っておきます。**

## モデル

**小さなローカルモデルは、フロンティアのモデルほどこれが得意ではありません。**
画面は同じでも、**推論は同じではありません**。

**汎用のオープンモデルは、ファイルのツールがあっても `grep` に手を伸ばします。**
ファイルを読む構造的な手段を渡しても、**agent 向けに訓練されていないモデルはシェルに出ます**。
**それはモデル側の欠落で、どんな画面もそれを埋めません。**
**このプロジェクトが変えられるのは到達範囲であって、賢さではありません。**

**ツールを呼ばないモデルは、この仕事をまったくできません。** 話をするだけです。
腰を据える前に[試してください](/reference/checking-a-model) —— 五分、固定の課題一つ。

## 数え方

**トークン数は常に見積もりで、数えたものではありません。** トークナイザーはモデルのもので、
**ここは見たこともないモデルを走らせます**。ASCII 四バイトで一トークン、
それ以外は一文字一トークン:**英語にも中国語にも近く**、その他では**多めに数える側**に寄せます。

**したがって、その下流はすべて近似です** —— 対話が要約されるとき、
ツールの出力が切られるとき、そして使用量の行が言うこと。

## スケジュール

**定時タスクと当番は、OpenCLI が開いている間だけ走ります。**
**これはサーバーではなくローカルのエージェント**です。マシンが眠っている間に発火しなければ
ならないものは、**OS のスケジューラー**の領分です。

## サンドボックス

**バックグラウンド実行は、走っているディレクトリの中なら何にでも書けます。**
**書き込み可能な根は、そのディレクトリ*そのもの*です。** 部門のディレクトリの外にある実行は、
**あなたがその場所を名指しで許可するまで保留されます** ——
**承認が never に設定されている場合を除き**、そのときは何も保留されません。

**読み取りはどのサンドボックスのモードでも、決して制限されません。**

## 何が変わったかの記録

**Artifacts に載るのは、エージェントのファイル編集ツールで行った編集だけです。**
エージェントが走らせたシェルコマンドが書いたファイル —— heredoc、スクリプト、
`git checkout` —— は追跡されず、現れません。**変更は本物です。一覧が不完全なのです。**

## デスクトップのビルド

**Apple や Microsoft の証明書で署名されていません。** あなたの OS は警告を出し、
**そうするのが正しい**のです:**誰が作ったか判別できない**のですから。
[インストール](/getting-started/install)に、何をすればよいか書いてあります。

## 画面

**右から左へ書く言語には対応していません。** アラビア語、ヘブライ語、ペルシア語は
翻訳ファイルとして足せますが、**ページは依然として左から右に並びます**。
**それは翻訳ではなくスタイルシートの変更です。**

## 上げる条件は指示であって保証ではありません

当番の *上げる条件* は、**モデルに義務として渡されます**。
**この製品が評価するのではありません**。つまり**それを読むモデルとまったく同じだけ
当てになります**。**確かめられる形で書いてください** —— *どれか一行でも 10,000 を超えたら* ——
*何かおかしければ* ではなく。
