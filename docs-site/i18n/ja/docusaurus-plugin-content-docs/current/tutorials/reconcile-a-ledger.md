# 帳簿の突き合わせを、最初から最後まで

**ローカルモデルで二十分。** 終わったときには、**毎朝二つのファイルを突き合わせ、
あなたが決めた閾値を超えるものを見つけたら止まって訊いてくる部門**が手元にあります。

**ここで使うのは同梱のサンプルデータだけ**なので、**何も準備しなくて構いません**。

## 1. 部門を作る

**Projects → すでに動くものから始める → Finance。**

`~/.opencli/workspace/finance` を作り、そこに三つのファイルを書き、二体のボットを雇います。

**ファイルにはわざと問題が仕込んであります**:

| ファイル | 中身 |
| --- | --- |
| `ledger.csv` | あなたの帳簿が言っていること |
| `statement.csv` | 銀行が言っていること |
| `overdue.csv` | 期日を過ぎた請求書 |

## 2. まず手で一度訊く

部門を開いて打ちます:

```
ledger.csv と statement.csv を比べて。合わない行を全部、参照番号と金額つきで
挙げて、何が起きたと思うか言って。
```

**何をするかを見ていてください。** これに向いたモデルは**両方のファイルをツールで読み**、
**行と参照番号で答えます**。向いていないモデルは、**中身を貼れと言うか、一般論で答えます** ——
そうなったら、**問題は設定ではなくモデルです**。[試してください](/reference/checking-a-model)。

## 3. 当番にする

**ボットは一度やりました。** 当番にすると、**それが自分から回ってくる**ようになります。

**Reconciler** ボットを開き、その当番を設定します:

| 欄 | 入れるもの |
| --- | --- |
| **何を** | `ledger.csv` と `statement.csv` を一行ずつ比べる。合わないものを参照番号と金額つきで挙げる。 |
| **規則** | 1.00 未満の差は端数。無視する。 |
| **上げる条件** | どれか一行でも 10,000 を超えたら。 |
| **間隔** | 24 時間 |

**「規則」と「何を」が分かれているのには理由があります**:仕事は毎朝同じで、
**閾値は誰かが見直す方針**です。一つのプロンプトに混ぜると、
**その数字を変えるのに指示全体を読み直す**ことになります。

## 4. 止まるところを見る

**Run now。** **サンプルデータには閾値を超える不一致が入っています**ので、
当番は最後まで行きません —— **答えられなかった問いとともに Bots → あなた待ちに現れます。**

**それがこの機能のすべてです。** 仕事をし、**あなたが引いた線に達し、
決める代わりに止まりました。**

答えてください。**あなたの答えは次の実行に持ち越されます**ので、同じことは二度訊きません。

## 5. 結果を渡す

Finance 部門には二体目のボット **Chaser** がついてきます。
Reconciler の **渡してよい相手** の一覧で、そこにチェックを入れます。

これで、合わない行を見つけた実行は、**やったことと作ったファイルを添えてそれを渡せます**。
Chaser は**背景を教えられなくても、顧客ごとに督促メールを一通ずつ起草します**。

**Bots → ボット間で渡された仕事** があとから連鎖を表示し、
**終わったからではなく段数が尽きて止まったもの**に印をつけます。

## いま手元にあるもの

- **エージェントが書いてよい、そこ以外にはないディレクトリ**
- **あなたが始めなくても起きる仕事**
- **止まって訊く、書かれた閾値**
- **一体目が置いたところから拾う二体目のボット**

## まず変えるもの

**閾値。** 10,000 は**例から来た数字**です。**あなたのものではありません。**

**規則。** 「1.00 未満の差は端数」は、**ある帳簿では真で、別の帳簿では違います**。

**間隔。** 24 時間ごとは**習慣であって法ではありません**。
**銀行が計上したあとに走る当番のほうが、真夜中に走るものより役に立ちます。**
