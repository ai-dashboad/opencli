# 大家真正會問的問題

## 我的資料會被發到哪裡?

**發到你設定的那個介面,不去別處。** 中間沒有我們的網關、沒有遙測帳號、二進制裡也
沒有內置任何金鑰。

如果那個介面就是你自己機器上的模型,**什麼都不會離開這臺機器**。

## 離線能用嗎?

能,配合本地模型。桌面端會檢查自己的更新,「模型」面板會拉一份熱門模型清單 ——
這兩件事在斷網時**安靜地失敗**,而且都不是聊天所必需的。

## 我需要 API 金鑰嗎?

**本地跑模型不需要。** Ollama、LM Studio、llama.cpp 這些都不用。用在線服務才需要
它自己的金鑰,而金鑰不會存進設定文件,保存之後也不會再顯示出來。

## 我該用哪個模型?

**你機器裝得下的那個,但有一條硬要求:它必須會調用工具。** 不會的話,它在這裡只能
聊天。

[測一個模型](/reference/checking-a-model)是個五分鐘的測試,直接回答這個問題。

## 為什麼它不如 Claude Code / Codex?

因為一個量化到能塞進筆記本的 27B 模型,不是 GPT-5。**介面是一樣的,推理不是。**

這個專案改變的是**可達性** —— 你手上這個模型能不能這樣用 —— 而不是它有多聰明。

## 能用 GPT-5 或者 Claude 嗎?

能。像設定任何其他 provider 一樣配 OpenAI 或 Anthropic。**產品內部不偏袒任何一家。**

## 對話從哪個目錄開始?

`~/.opencli/workspace`,除非它屬於某個部門,那樣就從那個部門的目錄開始。

以前是你的家目錄。**現在不是了**,因為沙箱的可寫根**就是**工作目錄 ——
見[沙箱與審批](/configuration/sandbox-and-approvals)。

## 幾個人能共用一個安裝嗎?

**不能。** 網關是單使用者設計的,它自己的源碼裡就這麼寫著。每個人跑自己那一份;後面
接一臺共享的模型伺服器是常見做法。

## 筆記本睡著的時候定時任務會跑嗎?

**不會。** 定時任務和值守只在 OpenCLI 開著的時候執行,因為這是個本地 agent 而不是
伺服器。必須在機器睡著時觸發的東西,屬於 `cron`、`launchd` 或任務計划程式。

## 跟 Open WebUI、Jan 有什麼區別?

**它們是本地模型的聊天介面**,而且做得很好。**這個是 agent**:它讀寫你的文件、執行
命令、並且在後臺繼續幹活。是不同的活兒,兩個一起用沒有任何問題。

## 跟它 fork 自的 Codex 有什麼區別?

Codex 是為 OpenAI 的模型做的。**部門、Bot、值守、後臺執行、Bot 之間的交接、內置的
那些流程、以及十種介面語言**,都是 fork 這一側加的;還有相當一部分工作是在處理
「模型小了會壞在哪裡」。

## 為什麼提示應用已損壞 / 無法驗證?

因為安裝檔沒有 Apple 或微軟的證書 —— 那要按年付費,這個專案還沒花。
[安裝](/getting-started/install)那頁寫了具體點哪裡。

## 能改成我自己的品牌名嗎?

**還不能。** 品牌是編譯進去的。

## 出問題了,去哪看?

[故障排查](/help/troubleshooting),然後是 `~/.opencli/log` 裡的日志,
再然後是[提一個 issue](https://github.com/ai-dashboad/opencli/issues)。
