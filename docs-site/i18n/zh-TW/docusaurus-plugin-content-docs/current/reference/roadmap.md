# 路線圖

**已知的事情,老實地標好類別。** 這裡沒有任何一條是帶日期的承諾 —— 這是個小專案,
**它守不住的日期比沒有日期更不值錢**。

## 正在做

**程式碼簽名。** 桌面端沒有 Apple 或微軟的證書,**這是產品裡最扎手的一處**:一個剛下載
好的東西第一次打開就告訴人出問題了,而其實什麼都沒出。它要按年付費,**這是它還沒發生
的唯一原因**。

**provider 目錄。** 現在配一個 provider 意味著寫一個你得去查的 `base_url`。
**已經驗證過四十家了 —— 那份清單應該在應用裡**,選一家是一次點擊,然後貼金鑰。

**把介面的組織方式改對。** 面板是按零件命名的 —— 產物、派發、定時 —— 而不是按活兒。
**其中三個餵的是同一個隊列,卻被擺成三個平級的東西。**

## 已知的缺口,還沒開始

**從右往左的版面。** 阿拉伯語、希伯來語、波斯語今天就能作為翻譯文件加進來,而頁面仍然
從左往右排。**那要改樣式表。**

**流程畫布。** Bot、值守、交接**已經構成一張圖** —— 它的資料就在磁碟上 —— 而沒有任何
地方能看到它。**現在一條鏈是一行文字。**

**白標。** 品牌是編譯進去的。

**一張多於一行的模型兼容表。** **這是任何人都能做的、最有用的貢獻**,而且不需要任何許可:
[測一個模型](/reference/checking-a-model),然後開個 PR。

## 明確不做的

**多使用者服務。** 網關是單使用者設計的。**一個讀你文件、在你機器上執行命令的 agent,
不會因為加了帳號系統就變成多租戶服務** —— 它會變成一個安全模型完全不同的產品。

**托管版本。** **你的資料沒有別的地方可去**,除了你自己選的那家模型服務商。

**我們自己的模型。** 這個東西不帶模型,對推理從哪來不持立場。**那就是它的意義。**

## 這個清單怎麼變

**它是儲存庫裡的一個文件**,有東西動了就改。如果第二段裡有你需要、而且你會用的東西,
[說一聲](https://github.com/ai-dashboad/opencli/issues) ——
**一個有人在等的缺口,和一個沒人問過的缺口,是兩回事。**
