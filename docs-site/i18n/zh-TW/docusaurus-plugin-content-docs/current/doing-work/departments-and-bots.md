# 部門與 Bot

一次對話就是一次對話。**會反復出現的活兒,需要一個比對話活得更久的東西。**

| | 是什麼 | 住在哪 |
| --- | --- | --- |
| **部門** | 一個目錄加一份常設說明 | 預設 `~/.opencli/workspace/<名字>` |
| **Bot** | 部門裡的一個會話,帶一份職責 | 那個部門 |
| **值守** | 自己到點的一份工作 | 一個 Bot |

這些詞是從辦公室借來的,**是有意的**。部門不是「取了個好名字的資料夾」——
**它是裡面的活兒能觸及範圍的邊界**。

## 從一個現成的開始

九個部門帶樣例資料一起裝好 —— 那些文件裡**問題是特意埋好的** —— 所以第一次執行會
真的做點什麼,而不是解釋說沒什麼可做。

| 部門 | 帶什麼來 |
| --- | --- |
| 財務 | 拿 `ledger.csv` 和 `statement.csv` 對賬;追逾期的款 |
| 客服 | 回覆進來的問題;按「真正在問什麼」歸類 |
| 運營 | 列出所有還沒發貨的訂單,以及各等了多少天 |
| 市場 | 把筆記變成一周的推文;按買過什麼給聯繫人分組 |
| 人事行政 | 拿簡歷對崗位;從會議記錄裡揪出決定和負責人 |
| 法務 | 逐條比對對方草案和我方條款,兩版都引出來 |
| 研究 | 研究之間在哪裡一致、在哪裡衝突、以及為什麼 |
| 病歷 | 記錄了什麼、醫生該看一眼哪裡,並引用原文 |
| 研發 | 讀一個服務,報出哪裡會給出錯誤的結果 |

**專案 → 或從一個現成的開始。** 它會建好目錄、寫入樣例文件、並把 Bot 招進來。

## 自己建一個

**專案 → 新建**,然後:

- **名字** —— 它叫什麼
- **資料夾** —— 不存在會自動創建
- **常設說明** —— 在這裡打開的**每一個**對話都會帶上它

常設說明是放「你本來每次都要重打一遍」的東西的地方:怎麼構建、什麼不許碰、哪些數字是
政策。它和上面那段描述是分開的 —— **描述只有你自己讀**。

## Bot

一個 Bot 就是一個帶職責的會話。**每次喚醒它,那份職責都會重新帶上**,所以不用再告訴它
一遍它是幹什麼的。

**員工**面板裡有四種狀態:

| | |
| --- | --- |
| **空閒** | 沒事做 |
| **工作中** | 有一次執行正在進行 |
| **等你** | 它停下來問你了 —— 見[值守](/doing-work/duties) |
| **出錯** | 上一次執行失敗了 |

## Bot 之間傳活兒

一個 Bot 可以**按名字**把活兒傳給另一個,**連同它做了什麼、產出了哪些文件**一起傳過去。
接手的那個從這些東西開始,而不是從零開始。

有三道拒絕防止它失控,**而這三道就是這個功能的實質**:

- **深度。** 一條鏈最多八跳。
- **重複。** 同一個 Bot 在一條鏈裡最多出現三次。
- **方向。** 一個 Bot 只能被**被允許的部門**交活兒。同一個部門內部永遠允許。

**員工**面板顯示每一條鏈,並且**標出那些「因為跳數用完而停,不是因為幹完了」的**。
