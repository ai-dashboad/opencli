# 連接器

連接器是 agent 用來調用工具的 MCP 服務 —— GitHub、一個資料庫、一個瀏覽器、你的文件。
**它是 agent 夠到「不是本機文件」的那些東西的方式。**

## 添加一個

**能力 → 連接器**列出已設定的和可添加的。從目錄裡加只要一次點擊;加自己的需要一個名字,
外加一條命令或一個地址:

| | |
| --- | --- |
| **本機命令** | 這臺機器上的一個程式,由 OpenCLI 啟動 |
| **HTTP 服務** | 一個通過 HTTP 能到達的服務 |

## 金鑰

大多數連接器需要金鑰。**填服務需要的環境變量名** —— 只填名字、空白分隔 —— 值隨後再設。

**值和你其他的金鑰存在一起,不在連接器的設定裡**,而且保存之後不會再顯示出來。
這是有意的:**設定文件會被分享、會被黏進 issue,裡面的金鑰會跟著一起走。**

## 測試

**測試連接**會啟動每一個已設定的服務並等待握手。它是一個**按鈕**,而不是打開面板就自動跑,
因為啟動它們要花幾秒 —— 對一個認證失敗的服務實測是 2.2 秒。

結果顯示在每一行上,連同那個服務提供的工具清單。

## 改動什麼時候生效

**服務是跟著對話啟動的。** 現在加的連接器對**下一個**打開的對話生效,不是眼前這個。

## 連接器不是什麼

**它不是模型獲得的能力。** 一個不肯調用工具的模型,不會因為加了連接器就開始調用 ——
見[做不到什麼](/reference/limits)。

## 部門

清單上方的標簽按部門篩選,**所以一個剛建好的財務部可以被問「這個該連什麼」,而不是
「Playwright 是什麼」**。

**沒有打部門標簽的連接器在每個標簽下都顯示** —— 沒人給它歸過類,不該等於對所有人隱藏。
