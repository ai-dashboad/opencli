# 值守

值守是一個 Bot 按周期執行的工作,**並且在碰到不該自己決定的事情時停下來問你**。

**最後那半句才是重點。** 任何東西都能按時跑一段提示詞;讓它對真實工作有用的,是
**它被事先告知了哪些事情不許它自己拍板**。

## 四個字段

```
做什麼        逐行比對 ledger.csv 和 statement.csv，
              列出對不上的，帶憑證號和金額。

規則          金額差小於 1.00 算捨入，忽略。

什麼時候問你   任何單筆超過 10000。

多久一次       24 小時
```

**「做什麼」和「規則」是特意分開的。** 活兒每天都一樣,而退款上限是**某個人會回頭修訂的
政策**。合成一段提示詞之後,改那個數字就得重讀整段指令才能找到它。

**「什麼時候問你」是用話寫的,不是一個條件表達式。** 它作為一項**義務**交給模型,不是
由產品去判斷 —— 也就是說,**它的可靠程度完全等於讀它的那個模型**。所以要寫成可核對的:
*任何單筆超過 10000*,而不是*任何異常*。

## 它停下來之後會怎樣

**值守停住。** 它帶著那個答不了的問題出現在**員工 → 等你答覆**裡,而且
**在你回覆之前不會再執行**。

你的回答會帶進下一次執行,**所以它不會為同一件事問第二遍**。

一個已經問過的值守**不會再提一個新問題** —— 它會重複那個還開著的。

## 它記住什麼

值守在兩次執行之間**留筆記**。學到一件事的那次執行只寫下那一件;它**不必把已經知道的
重述一遍**,而一次跑到一半失敗的執行**也不會把其餘的筆記帶走**。

寫一個空值,就是**故意忘掉**某件事。

## 它在哪裡執行

在那個 Bot 的部門目錄裡,**而那就是這次執行能寫入的全部範圍**。指向別處的值守會被扣住,
等你按名字授權 —— 見[沙箱與審批](/configuration/sandbox-and-approvals)。

## 值守和定時任務

兩者都是按時跑一段提示詞。**區別在於它屬於誰。**

| | 屬於 | 會升級 | 會記憶 |
| --- | --- | --- | --- |
| **值守** | 一個部門裡的一個 Bot | 會 | 會 |
| **定時任務** | 不屬於任何東西 | 不會 | 不會 |

「每天早上九點告訴我有什麼變化」用定時任務。**帶著政策的活兒用值守。**
