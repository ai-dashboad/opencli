# 盯一個資料夾,報告變化

**十分鐘。** 做完之後,會有個東西按你定的周期給你寫一份簡報,說這個目錄裡動了什麼 ——
一個專案、一塊共享盤、或者某個人老往裡放東西的資料夾。

## 1. 把一個對話指向這個資料夾

新開一個對話,用輸入框上方的資料夾按鈕選目錄。

**這件事比看起來重要:agent 可以寫一個對話所在目錄裡的任何地方,目錄之外一個字都寫不了。**
**選資料夾就是在選爆炸半徑。**

## 2. 先讓它寫一次

```
用 weekly-report 技能處理這個資料夾。
```

`weekly-report` 是內置技能。它會算出變了什麼 —— 是儲存庫就從 git 裡算,否則看修改時間 ——
然後寫三段:**做完的、在做的、以及需要誰拍板的**。

**最後那一段才是這份報告被讀的理由。**

## 3. 排成定時的

**後臺執行 → 排一個重複的:**

| 字段 | |
| --- | --- |
| **做什麼** | 用 weekly-report 技能處理這個資料夾。存成 `report-<日期>.md`。 |
| **名稱** | 周報 |
| **多久一次** | 7 天 |
| **在哪裡執行** | 你選的那個資料夾 |

## 4. 確認它會在哪裡跑

**如果那個資料夾不在你的工作區裡、也不是一個部門,第一次執行會被扣住**而不是啟動,
出現在*等你授權*下面。

**這是有意的。** 授權那個目錄,或者把任務移進一個部門。

## 5. 讀第一份

**立即執行**,然後打開這次執行,輸出是產出多少看多少。

如果報告很薄,**說明這個資料夾這周本來就很薄** —— 這個技能被要求用一行說清楚,而不是
湊字數,因為**一份從空白周湊出來的報告,會教會人跳過報告**。

## 如果盯的是別人的資料夾

有兩件事值得小心。

**agent 會讀它被指向的一切**,而且**讀取在任何沙箱模式下都不受限**。一個裝著「你不會
發給你的模型服務商」的東西的資料夾,就不該是你指向的那個 —— **除非你的模型跑在自己
機器上,那樣什麼都不會離開**。

**一個定時任務活得比你的注意力長。** 每周跑一次、跑一年,就是**五十二次你沒看過的執行**。
把目錄範圍收緊。
