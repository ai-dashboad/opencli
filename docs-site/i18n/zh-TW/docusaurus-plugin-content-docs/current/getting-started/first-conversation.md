# 第一次對話

## 它從哪裡開始

新對話在 `~/.opencli/workspace` 開始,除非它屬於某個部門 —— 那樣就在那個部門的目錄裡。

**這件事比看起來重要。** agent 的沙箱可以寫它工作目錄裡的任何東西,所以**一個對話打開
在哪個目錄,就是它能改動的全部範圍**。以前預設是你的家目錄,現在不是了,原因在
[沙箱與審批](/configuration/sandbox-and-approvals)。

用輸入框上方的資料夾按鈕可以換目錄。

## 要它做點什麼

用普通的句子。它有你的文件、一個 shell,以及你加過的[連接器](/doing-work/connectors):

```
讀 invoices.csv，列出所有違反 rules.md 裡規則的行
```

```
這個儲存庫上周有什麼變化？
```

```
比較 their-draft.md 和 our-terms.md，列出所有有差異的條款
```

## 改動之前會發生什麼

預設情況下,**一條不確定安全的命令在執行前會先給你看**,一次文件寫入在落盤前也會先給
你看。逐個批准或拒絕。

三種設定,在**個性化**裡:

| | |
| --- | --- |
| **不熟悉的先問** | 所有不是已知安全的命令,都先給你看 |
| **失敗了才問** | 命令自己跑,需要更大權限時才來問你 |
| **從不問** | 執行前什麼都不顯示 |

最後一種是給「你願意讓指令碼在裡面撒野的目錄」用的。詳見
[沙箱與審批](/configuration/sandbox-and-approvals)。

## 看它做了什麼

**產物**列出這次對話裡 agent 編輯過的文件,帶 diff。

有一條誠實的限制:**這裡只列用 agent 的文件編輯工具做的改動**。它執行的 shell 命令寫的
文件 —— heredoc、指令碼、`git checkout` —— **不被追蹤,不會出現在那裡**。

## 當它開始說不清話的時候

一個變長的對話會被總結,好讓它繼續裝得下。你會看到**「正在壓縮對話…」**,之後執行緒會
帶著一份摘要繼續,替代較早的那些輪次。

如果**壓縮幫不上忙** —— 因為長度來自工具描述而不是對話本身 —— 它會**說一次**,而不是
每一輪都再壓一遍。
