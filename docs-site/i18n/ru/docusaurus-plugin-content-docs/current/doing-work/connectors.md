# Коннекторы

**Коннектор — это MCP-сервер, через который агент может вызывать инструменты**:
GitHub, база данных, браузер, ваши файлы. Это **способ, которым агент дотягивается
до чего-то, что не является файлом на этой машине**.

## Добавить коннектор

**Abilities → Connectors** перечисляет то, что настроено, и то, что можно
добавить. Добавить из каталога — один щелчок; добавить свой — нужны имя и либо
команда, либо URL:

| | |
| --- | --- |
| **Локальная команда** | программа на этой машине, запускаемая OpenCLI |
| **HTTP-сервер** | сервер, доступный по HTTP |

## Ключи

**Большинству коннекторов ключ нужен.** Назовите переменные окружения, которых
ждёт сервер, — **только имена**, через пробел — а **значения задайте потом**.

**Значения хранятся вместе с остальными вашими ключами, а не в конфигурации
коннектора**, и **после сохранения больше не показываются**. Это сделано
намеренно: **файл конфигурации отдают другим и вставляют в issue, и лежащий в нём
ключ уходит вместе с ним.**

## Проверка

**Test connections** запускает каждый настроенный сервер и ждёт рукопожатия. Это
кнопка, а не то, что происходит при открытии панели, потому что **запуск занимает
секунды** — измерено **2,2** на сервере, который не проходит аутентификацию.

Результат появляется в каждой строке, **вместе с инструментами, которые этот
сервер предлагает**.

## Когда изменение вступает в силу

**Серверы стартуют вместе с разговором.** Коннектор, добавленный сейчас,
относится к **следующему** открытому разговору, а не к тому, что перед вами.

## Чем коннектор не является

**Это не способность, которую приобретает модель.** Модель, которая не вызывает
инструменты, **не начнёт их вызывать оттого, что добавили коннектор** — см.
[Ограничения](/reference/limits).

## Отделы

Метки над списком фильтруют по отделу, так что у только что созданного
финансового отдела можно спросить *с чем это должно быть связано*, а не *что такое
Playwright*.

**Коннектор без метки отдела показывается под каждой из них**: **то, что никто не
разнёс по категориям, не должно быть спрятано от всех.**
