# Отделы и боты

**Разговор — это один разговор.** Работе, которая возвращается, нужно что-то,
**что его переживёт**.

| | Что это | Где живёт |
| --- | --- | --- |
| **Отдел** | каталог плюс постоянные указания | по умолчанию `~/.opencli/workspace/<имя>` |
| **Бот** | разговор внутри отдела, у которого есть работа | в этом отделе |
| **Дежурство** | работа, которая возвращается сама | у бота |

**Слова взяты из офиса намеренно.** Отдел — не «папка с красивым названием»:
это **граница того, к чему работа внутри может прикасаться**.

## Начать с того, что уже работает

**Девять отделов идут с примерами данных** — файлами, в которые заранее
заложены проблемы, — чтобы первый запуск **что-то сделал**, а не объяснил, что
делать нечего.

| Отдел | Что идёт в комплекте |
| --- | --- |
| Финансы | Свести `ledger.csv` со `statement.csv`; напомнить о просроченном |
| Поддержка | Ответить на пришедшее; сгруппировать вопросы по тому, о чём они на самом деле |
| Операции | Перечислить все неотгруженные заказы и сколько каждый ждёт |
| Маркетинг | Превратить заметки в неделю постов; разбить контакты по покупкам |
| Кадры и админ | Прочитать кандидатов под вакансию; вытащить из заметок решения и ответственных |
| Юридический | Сверить их проект с нашими условиями, пункт за пунктом, цитируя оба |
| Исследования | Где работы сходятся, где противоречат друг другу и почему |
| Медкарты | Что записано и на что стоит взглянуть врачу, с цитатой |
| Инженерия | Прочитать сервис и доложить, что дало бы неверный ответ |

**Projects → или начните с того, что уже работает.** Он создаст каталог,
запишет примеры файлов и наймёт ботов.

## Сделать свой

**Projects → New**, затем:

- **Имя** — как он называется
- **Папка** — создаётся, если её нет
- **Постоянные указания** — выдаются агенту в ***каждом*** открытом здесь
  разговоре

**Постоянные указания — это место для того, что иначе пришлось бы набирать
заново**: как собирать, что не трогать, какие числа — политика. Они отделены от
описания, которое **читаете только вы**.

## Боты

**Бот — это разговор с работой.** Эта работа **подаётся заново каждый раз, когда
бота будят**, так что ему не нужно снова объяснять, зачем он.

Четыре состояния, в панели **Bots**:

| | |
| --- | --- |
| **Простаивает** | делать нечего |
| **Работает** | запуск идёт |
| **Ждёт вас** | остановился и спросил — см. [Дежурства](/doing-work/duties) |
| **Ошибка** | последний запуск не удался |

## Боты передают работу друг другу

Бот может передать работу другому **по имени**, вместе с тем, что он сделал, и
файлами, которые он получил. Принимающий **начинает с этого, а не с пустого
места**.

**Три отказа** не дают этому разбежаться — и в них вся суть:

- **Глубина.** Цепочка ограничена **восемью переходами**.
- **Повторы.** Один бот не может встречаться в цепочке **больше трёх раз**.
- **Направление.** Боту может передать работу **только отдел, которому это
  разрешено**. Внутри одного отдела разрешено всегда.

Панель **Bots** показывает каждую цепочку и **отмечает те, что остановились не
потому, что закончили, а потому, что кончилась верёвка**.
