# Навыки

**Навык — это набор указаний, к которому агент обращается, когда задача того
требует**: процедура, записанная один раз, **а не вставляемая в промпт каждый
раз**.

## Что идёт в комплекте

**Шесть процедур поставляются с продуктом и работают в любом каталоге**:

| Навык | Что делает |
| --- | --- |
| `spreadsheet-review` | Сверяет файл со строками с изложенными в нём правилами и сообщает о нарушающих строках **с их номерами** |
| `weekly-report` | Что здесь **действительно изменилось** за период: сделано, в работе и что требует решения |
| `inbox-triage` | Раскладывает сообщения по тому, о чём они просят, и **помечает те, на которые должен ответить человек** |
| `document-compare` | Что изменилось **по существу** между двумя черновиками — отдельно от того, **что изменилось только в формулировках** |
| `meeting-notes` | Расшифровка превращается в решения, задачи с ответственными и открытые вопросы |
| `records-review` | Поднимает то, что стоит проверить в наборе записей, **цитируя заметку, из которой это взято** |

Ещё два, унаследованных, — про **написание и установку самих навыков**:
`skill-creator` и `skill-installer`.

## Откуда они берутся

| Область | Каталог |
| --- | --- |
| Встроенные | `~/.opencli/skills/.system` — переписывается при обновлении приложения |
| Ваши | `~/.opencli/skills` |
| Этого проекта | `.opencli/skills` в рабочем каталоге |

## Написать свой

Каталог с файлом `SKILL.md`, во front matter которого сказано, что это и
**когда этим пользоваться**:

```markdown
---
name: invoice-check
description: Check invoices against our payment rules and report what breaks
  them. Use when asked to review, check or audit a file of invoices.
metadata:
  short-description: Find invoices that break the rules
---

# Invoice check

## Find the rules before reading the rows
...
```

**Именно с `description` агент сопоставляет запрос.** Описание, которое говорит
лишь о том, чем навык ***является***, **оставляет модели догадываться, когда он
применим**: **каждый встроенный навык называет свои поводы**, и ваш тоже должен.

## Что делает навык работающим

**Прочитать шесть встроенных — самый быстрый способ увидеть форму**, но три вещи
повторяются:

- **Скажите, что читать и в каком порядке.** «Сначала самое старое» — настоящее
  указание; «просмотри записи» — нет.
- **Скажите, что должно получиться.** Файл с именем или названная структура. Не
  «сводка».
- **Скажите, чего делать нельзя никогда.** Встроенный навык для медкарт
  **тратит на это треть своей длины**, и именно поэтому он может существовать.

**Одно выучено на своей шкуре**: если число важно, **скажите, откуда это число
должно взяться**. Табличный навык требует счётчик строк, и **первый запуск назвал
его по памяти и ошибся на единицу**. Теперь он требует, **чтобы число приходило
из скрипта, который и делал проверку**.

## Выключить навык

У каждого навыка есть переключатель в **Abilities → Skills**. Изменение
относится к **следующему открытому разговору**, а не к уже идущему.
