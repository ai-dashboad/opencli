# Первый разговор

## Где он начинается

Новый разговор открывается в `~/.opencli/workspace` — если только он не
принадлежит отделу, тогда он открывается в каталоге этого отдела.

**Это важнее, чем кажется.** Песочница агента может писать куда угодно внутри
своего рабочего каталога, поэтому **каталог, в котором открыт разговор, — это
всё, что он может изменить**. Раньше по умолчанию была ваша домашняя папка;
теперь нет, и причина — в
[Песочнице и подтверждениях](/configuration/sandbox-and-approvals).

Сменить его можно кнопкой с папкой над полем ввода.

## Попросить о чём-нибудь

Обычными фразами. У агента есть ваши файлы, оболочка и те
[коннекторы](/doing-work/connectors), которые вы добавили:

```
Прочитай invoices.csv и перечисли все строки, нарушающие правила из rules.md
```

```
Что изменилось в этом репозитории за последнюю неделю?
```

```
Сравни their-draft.md с our-terms.md и перечисли все расходящиеся пункты
```

## Что происходит, прежде чем что-то изменится

По умолчанию агент **показывает команду, которая не признана безопасной, до
запуска**, и **показывает запись в файл до того, как её сделать**. Каждое
действие вы подтверждаете или отклоняете.

Три настройки, в **Customize**:

| | |
| --- | --- |
| **Спрашивать обо всём незнакомом** | каждая команда, не признанная безопасной, показывается заранее |
| **Спрашивать только после сбоя** | команды выполняются без присмотра; вас спрашивают, когда какой-то нужен более широкий доступ |
| **Не спрашивать никогда** | перед запуском ничего не показывается |

Последнее — для каталога, **в котором вы дали бы волю скрипту**. Как следует
это объяснено в
[Песочнице и подтверждениях](/configuration/sandbox-and-approvals).

## Посмотреть, что он сделал

**Artifacts** перечисляет файлы, которые агент правил в этом разговоре, вместе
с диффами. Одно честное ограничение: **сюда попадают только правки, сделанные
файловым инструментом агента**. Файлы, записанные выполненной им shell-командой
— heredoc, скрипт, `git checkout` — не отслеживаются и здесь не появятся.

## Когда перестаёт помещаться

Разросшийся разговор **сжимается в пересказ, чтобы продолжать помещаться**. Вы
увидите **Summarising the conversation…**, и дальше ветка продолжается с
пересказом вместо старых ходов.

**Если пересказ не поможет** — потому что длина берётся из схем инструментов, а
не из разговора — **он говорит об этом один раз, а не повторяет попытку каждый
ход**.
