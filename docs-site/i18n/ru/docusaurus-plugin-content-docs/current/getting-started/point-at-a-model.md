# Указать модель

**В OpenCLI нет ни модели, ни ключа.** На свежей установке первый экран прямо
об этом говорит и предлагает два пути ниже.

**Это не список интеграций, а один протокол.** Всё, что отвечает на
`/v1/chat/completions` и `/v1/models` так же, как OpenAI, можно указать, и
**его модели появятся в списке сами**. Объявлять их по одной не нужно.

## На этой машине

Настольное приложение может установить модель за вас: откройте **Models**, и
оно посмотрит, **что уже есть на машине**, прежде чем предлагать что-то
скачивать.

Вручную, при уже запущенной [Ollama](https://ollama.com):

```toml
model = "qwen3-coder"

[model_providers.ollama]
name = "Ollama"
base_url = "http://localhost:11434/v1"
wire_api = "chat"

[[models]]
slug = "qwen3-coder"
model = "qwen3-coder:30b"
provider = "ollama"
context_window = 32768
```

Положите это в `~/.opencli/config.toml` и запустите `opencli`.

**Ничего не покидает машину, и никакого ключа хранить не нужно.**

## Поставщик

**Все они устроены одинаково.** Схема — базовый URL и имя переменной окружения,
в которой лежит ключ:

```toml
model = "my-model"

[model_providers.my-provider]
name = "My Provider"
base_url = "https://api.example.com/v1"
env_key = "MY_PROVIDER_API_KEY"
wire_api = "chat"
```

```shell
export MY_PROVIDER_API_KEY=...
opencli
```

В настольном приложении то же самое делается в **Settings**, где ключ
**сохраняется и больше никогда не показывается**.

### Бесплатные квоты — самый дешёвый способ попробовать большую модель

Несколько поставщиков что-то отдают даром, и именно так запускают модель,
**которая гораздо больше, чем поместилось бы на вашей машине**. Что именно
бесплатно, меняется от месяца к месяцу, поэтому здесь не названо ни одной
цифры — **смотрите их собственные страницы с ценами**.

В [README](https://github.com/ai-dashboad/opencli#where-the-model-comes-from)
есть полный список поставщиков, **каждый проверен запросом его списка моделей**.

## Модель может приходить не от той компании, что её сделала

Xiaomi выпускает MiMo, ByteDance выпускает Seed, и **ни та, ни другая не держит
собственную публичную OpenAI-совместимую точку доступа**. Обе модели раздают
другие — то есть до MiMo вы добираетесь через OpenRouter, Novita, DeepInfra,
PPIO или Hugging Face, а не через Xiaomi.

## Быть доступным — не то же самое, что быть в этом хорошим

**Поставщик, который отвечает на OpenAI API, но не на его часть с вызовом
инструментов, будет разговаривать — и почти ничего больше**: этот агент
работает, вызывая инструменты. Прежде чем ставить на модель,
[проверьте её](/reference/checking-a-model) — **пять минут, одна фиксированная
задача**.
