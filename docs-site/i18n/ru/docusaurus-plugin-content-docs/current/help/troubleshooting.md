# Устранение неполадок

## Пишет, что учётные данные отклонены

```
The model provider would not accept the request without credentials.
(status 401 Unauthorized)
```

**Либо для выбранного поставщика ключ не задан, либо заданный для него не
годится.** Три вещи, которые надо проверить **по порядку**:

1. **Какой поставщик выбран на самом деле** — `model` в `config.toml` или список
   выбора над полем ввода. **Указание на модель, чьего поставщика вы никогда не
   настраивали**, — самая частая причина.
2. **Переменная окружения, названная в `env_key`**, задана в той оболочке, где
   работает агент. **Настольное приложение читает её оттуда, где хранит ваши ключи,
   а не из вашей оболочки.**
3. **Ключ принадлежит именно этому поставщику.** Ключ одного — не ключ другого.

**401 намеренно не повторяется**: **учётные данные не становятся действительными
оттого, что их предъявили ещё раз.**

## Список моделей пуст

Панель **Models** и список выбора над полем ввода берутся из `/v1/models`
поставщика. **Пустой список означает, что этот запрос не удался**, а причина — в
`~/.opencli/log`.

**Поставщик, которому нужен ключ, без ключа не возвращает ничего**, так что это и
401 выше — **обычно одна и та же беда**.

## Он отвечает, но никогда не трогает мои файлы

**Ваша модель не вызывает инструменты.** Это **самое частое разочарование**, и
**это не ошибка настройки**: **некоторые модели просто не вызывают**.

[Проверьте её](/reference/checking-a-model). Пять минут, одна фиксированная
задача. **Если провалится, то модель — неподходящий инструмент для этого, и
никакая настройка этого не изменит.**

## Он запускает `grep` вместо того, чтобы нормально прочитать файл

**Тот же изъян по сути, только в мягкой форме**: модель, не обученная агентной
работе, **тянется к оболочке, даже когда файловый инструмент прямо перед ней**.
**Ничто в интерфейсе этот разрыв не закрывает.**

## Фоновый запуск пишет, что ждёт меня

**Его рабочий каталог — не из тех, что продукт знает**: не рабочее пространство,
не каталог отдела и не **место, которое вы разрешили поимённо**.

Либо **Разрешить этот каталог** в панели Dispatch, либо **перенесите** задачу в
отдел. **Его придерживают, а не запускают, потому что запуск может писать куда
угодно внутри своего каталога.**

## Запланированная задача так и не выполнилась

**Две возможности**:

- **OpenCLI был закрыт.** Запланированная работа идёт **только пока он открыт**.
- **Её придержали**, как выше. Придержанные задачи появляются в разделе
  *Ждёт вас*.

## Разговор всё время сам себя пересказывает

**Если он сжался и тут же требуется снова, длина берётся не из разговора**: она из
**неизменной части каждого запроса**, а это по большей части **схемы инструментов
ваших коннекторов**. **Четыре коннектора — это десять тысяч токенов ещё до того,
как вы что-то сказали.**

**Он говорит об этом один раз, а не повторяет каждый ход.** Лекарство —
**отключить коннекторы, которыми вы в этом разговоре не пользуетесь**.

## Настольное приложение не открывается

**macOS**: выполните `xattr -dr com.apple.quarantine /Applications/OpenCLI.app`
или щёлкните правой кнопкой → **Открыть**.

**Windows**: SmartScreen → **Подробнее** → **Выполнить в любом случае**.

Если оно всё равно отказывается, **загрузка могла оказаться неполной** — сверьте
размер файла со страницей релиза.

## Агент сделал что-то, чего я не видел

**Artifacts перечисляет только правки, сделанные файловым инструментом агента.**
Файлы, записанные выполненной им shell-командой — heredoc, скрипт,
`git checkout`, — **это настоящие изменения, и там они не появятся**.

**`git status` в рабочем каталоге — надёжный ответ.**

## Интерфейс на английском, хотя я выбрал другой язык

**Словарь подгружается, когда выбирают его язык**, поэтому есть **момент, когда
виден английский**. Если английский остался, **кусок не загрузился** — посмотрите
консоль браузера в инструментах разработчика настольного приложения.

**Фраза без перевода всегда показывается по-английски — так задумано**; это
**частичный перевод, а не неисправность**.

## Где журналы

```
~/.opencli/log
```

**Settings → About → Logs** открывает этот каталог. При сообщении о проблеме
**последних пятидесяти строк вокруг сбоя почти всегда достаточно** — и **прежде чем
вставлять, просмотрите их на предмет ключей**.
