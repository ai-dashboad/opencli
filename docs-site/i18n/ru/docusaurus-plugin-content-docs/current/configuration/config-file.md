# Файл конфигурации

`~/.opencli/config.toml`. **У всего здесь есть значение по умолчанию**; файл
хранит только **то, что вы изменили**.

**Настольное приложение пишет в тот же файл, сохраняя ваши комментарии и
форматирование**, так что **править вручную и править в Settings — одно и то же
действие**.

## Поставщики и модели

**Поставщик — это базовый URL и имя переменной окружения, в которой лежит ключ**:

```toml
[model_providers.my-provider]
name = "My Provider"
base_url = "https://api.example.com/v1"
env_key = "MY_PROVIDER_API_KEY"
wire_api = "chat"
```

Объявленные под ним модели появляются в списке выбора:

```toml
model = "my-model"

[[models]]
slug = "my-model"
model = "provider-side-model-id"
provider = "my-provider"
display_name = "My Model"
context_window = 128000
reasoning_efforts = ["low", "medium", "high"]
```

`slug` — это **то, что набираете вы**; `model` — **то, как это называет
поставщик**. **Они расходятся достаточно часто, чтобы их стоило разделить.**

**Объявлять их не обязательно.** Модели забираются из `/v1/models` поставщика.
Объявление нужно, чтобы **закрепить окно контекста, отображаемое имя или
принимаемые уровни усилия**.

## Подтверждения и песочница

```toml
approval_policy = "on-failure"   # untrusted | on-failure | never
sandbox_mode = "workspace-write" # read-only | workspace-write | danger-full-access
```

Объяснено в
[Песочнице и подтверждениях](/configuration/sandbox-and-approvals).

## Вывод инструментов

```toml
tool_output_token_limit = 10000
```

**Бюджет на то, сколько вывод инструмента может добавить к разговору.**

**Токены оцениваются, а не считаются.** Токенизатор принадлежит модели, а **здесь
запускаются модели, которых он никогда не видел**. Оценка такова: **четыре
ASCII-байта на токен и один токен на символ во всех прочих случаях** — близко и
для английского, и для китайского, **с перекосом в сторону завышения** в
остальном. Поставить сюда 500 **не значит обрезать ровно на 500 токенах**;
**обрежется рядом, в тех же единицах, в которых написано число**.

## Посмотреть, что действует

**Settings** показывает **каждое действующее значение и откуда оно взялось**,
включая **те, которых вы никогда не задавали**. `Show raw config` — это сам файл.
