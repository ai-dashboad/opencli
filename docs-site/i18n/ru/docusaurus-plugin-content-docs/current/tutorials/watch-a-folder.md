# Следить за папкой и докладывать, что изменилось

**Десять минут.** В итоге у вас есть **нечто, что с выбранной вами
периодичностью пишет короткий отчёт о том, что сдвинулось в каталоге** — проекте,
общем диске, **папке, в которую кто-то другой постоянно что-то кладёт**.

## 1. Направьте разговор на папку

Откройте новый разговор и выберите каталог кнопкой с папкой над полем ввода.

**Это важнее, чем кажется**: **агент может писать куда угодно внутри каталога, в
котором открыт разговор**, и никуда за его пределами. **Выбрать папку — значит
выбрать радиус поражения.**

## 2. Попросите отчёт один раз

```
Примени навык weekly-report к этой папке.
```

Навык `weekly-report` идёт с продуктом. **Он выясняет, что изменилось** — из git,
если папка является репозиторием, и из времени изменения файлов, если нет, — и
пишет три раздела: **что завершено, что в работе и что требует решения**.

**Ради последнего раздела его и читают.**

## 3. Поставьте на расписание

**Фоновые запуски → запланируйте повторяющийся:**

| Поле | |
| --- | --- |
| **Что он должен делать** | Примени навык weekly-report к этой папке. Сохрани как `report-<date>.md`. |
| **Название** | Недельный отчёт |
| **Как часто** | 7 дней |
| **Где выполнять** | папка, которую вы выбрали |

## 4. Проверьте, где он будет выполняться

**Если папка не внутри вашего рабочего пространства и не является отделом,
первый запуск будет придержан**, а не начат, и появится в разделе *Ждёт вас*.

**Это сделано намеренно.** Разрешите каталог или перенесите задачу в отдел.

## 5. Прочитайте первый

**Run now**, затем откройте запуск и **читайте вывод по мере его появления**.

**Если отчёт вышел тощим, значит, у папки была тощая неделя**: навыку велено
**сказать это одной строкой, а не разводить воду**, потому что **отчёт, раздутый
из пустой недели, учит людей пропускать отчёты**.

## Делать это с чужой папкой

**Две вещи, с которыми стоит быть осторожнее.**

**Агент читает всё, на что его направили**, и **чтение не ограничивается
песочницей ни в одном режиме**. **Папка с тем, что вы не отправили бы своему
поставщику моделей, не должна быть той папкой, на которую вы его направляете** —
**если только модель не на вашей собственной машине**, тогда наружу не уходит
ничего.

**Расписание переживает ваше внимание.** То, что запускается еженедельно в течение
года, — это **пятьдесят два запуска, за которыми вы не наблюдали**. **Держите
каталог узким.**
