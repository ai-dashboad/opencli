# Vigilar una carpeta e informar de lo que cambió

**Diez minutos.** Al final tendrás **algo que te escribe un informe breve de lo
que se movió en un directorio, con la periodicidad que elijas**: un proyecto, una
unidad compartida, **una carpeta donde otra persona no deja de meter cosas**.

## 1. Apunta un chat a la carpeta

Abre un chat nuevo y usa el botón de carpeta sobre el campo de escritura para
elegir el directorio.

**Esto importa más de lo que parece**: **el agente puede escribir en cualquier
punto del directorio en el que está abierto un chat**, y en ningún sitio fuera de
él. **Elegir la carpeta es elegir el radio de la explosión.**

## 2. Pide el informe una vez

```
Usa la habilidad weekly-report en esta carpeta.
```

La habilidad `weekly-report` viene con el producto. **Averigua qué cambió** —de
git si la carpeta es un repositorio, y de las fechas de modificación si no— y
escribe tres secciones: **lo que terminó, lo que está en marcha y lo que necesita
una decisión**.

**Esa última sección es la razón para leerlo.**

## 3. Ponlo en un horario

**Ejecuciones en segundo plano → programa una repetitiva:**

| Campo | |
| --- | --- |
| **Qué debe hacer** | Usa la habilidad weekly-report en esta carpeta. Guárdalo como `report-<date>.md`. |
| **Nombre** | Informe semanal |
| **Cada cuánto** | 7 días |
| **Dónde ejecutarlo** | la carpeta que elegiste |

## 4. Comprueba dónde se va a ejecutar

**Si la carpeta no está dentro de tu espacio de trabajo y no es un departamento,
la primera ejecución quedará retenida** en lugar de arrancar, y aparecerá bajo
*Esperándote*.

**Es deliberado.** Autoriza el directorio, o mueve la tarea a un departamento.

## 5. Lee el primero

**Run now**, y luego abre la ejecución para **leer la salida según se produce**.

**Si el informe sale flojo, la carpeta tuvo una semana floja**: a la habilidad se
le dice que **lo diga en una línea en vez de rellenar**, porque **un informe
inflado a partir de una semana vacía enseña a la gente a saltarse los informes**.

## Hacer esto con la carpeta de otra persona

**Dos cosas que conviene cuidar.**

**El agente lee todo aquello a lo que se le apunta**, y **las lecturas no están
restringidas por el sandbox en ningún modo**. **Una carpeta con cosas que no
enviarías a tu proveedor de modelos no debería ser la carpeta a la que lo
apuntas** — **salvo que tu modelo esté en tu propia máquina**, en cuyo caso no
sale nada de ella.

**Un horario sobrevive a tu atención.** Algo que se ejecuta semanalmente durante
un año son **cincuenta y dos ejecuciones que no miraste**. **Mantén el directorio
estrecho.**
