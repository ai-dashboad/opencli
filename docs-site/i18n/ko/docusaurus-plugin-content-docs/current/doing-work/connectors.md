# 커넥터

**커넥터는 에이전트가 도구를 불러 쓰는 MCP 서버**입니다 —— GitHub, 데이터베이스,
브라우저, 당신의 파일. **이 기계의 파일이 아닌 무언가에 에이전트가 손을 뻗는 방법**입니다.

## 하나 추가하기

**Abilities → Connectors** 가 설정된 것과 추가할 수 있는 것을 보여 줍니다.
카탈로그에서 넣는 건 한 번 클릭이고, 직접 넣으려면 이름과 명령 또는 URL이 필요합니다:

| | |
| --- | --- |
| **로컬 명령** | 이 기계에 있는 프로그램. OpenCLI가 띄웁니다 |
| **HTTP 서버** | HTTP로 닿을 수 있는 서버 |

## 키

**대부분의 커넥터에는 키가 필요합니다.** 서버가 기대하는 환경 변수의 **이름만**
공백으로 나눠 적고, **값은 나중에 넣습니다.**

**값은 커넥터 설정이 아니라 당신의 다른 키들과 함께 보관되고**,
**한 번 저장하면 다시는 보이지 않습니다.** 이건 의도적입니다:
**설정 파일은 공유되고 이슈에 붙여지며, 안에 든 키는 그것을 따라갑니다.**

## 시험하기

**Test connections** 는 설정된 서버를 모두 띄우고 핸드셰이크를 기다립니다.
패널을 열 때 저절로 도는 대신 **버튼**인 이유는 **띄우는 데 몇 초가 걸리기 때문**입니다 ——
인증에 실패하는 서버 하나에서 **2.2초**로 재었습니다.

결과는 각 줄에, **그 서버가 제공하는 도구와 함께** 나타납니다.

## 바뀐 것이 언제 반영되는가

**서버는 대화와 함께 시작합니다.** 지금 추가한 커넥터는 **눈앞의 대화가 아니라
다음에 여는 대화**에 반영됩니다.

## 커넥터가 아닌 것

**그것은 모델이 얻는 능력이 아닙니다.** 도구를 부르지 않는 모델은
**커넥터를 추가했다고 부르기 시작하지 않습니다** ——
[한계](/reference/limits)를 보세요.

## 부서

목록 위의 칩은 부서로 걸러 줍니다. 그래서 갓 만든 재무 부서에 대고
*여긴 무엇과 연결되어야 하지* 라고 물을 수 있습니다 —— *Playwright가 뭐지* 가 아니라.

**부서 태그가 없는 커넥터는 모든 칩 아래에 나타납니다**:
**아무도 분류하지 않은 것을 모두에게서 숨겨서는 안 됩니다.**
