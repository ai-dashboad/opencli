# OpenCLI

### 직접 돌리는 모델을 위한 에이전트

당신의 컴퓨터에서 돌아가고, OpenAI 호환 모델이면 무엇이든 쓸 수 있으며, 설명하는 대신 일을 합니다. 파일을 읽고, 명령을 실행하고, 작업물을 고치고, 자리를 비운 사이에도 백그라운드에서 계속합니다.

</div>

## 실행하기

<Tabs groupId="install">
<TabItem value="macos" label="macOS" default>

[`OpenCLI-macos-aarch64.dmg`](https://github.com/ai-dashboad/opencli/releases/latest/download/OpenCLI-macos-aarch64.dmg)(Apple Silicon) 또는
[`OpenCLI-macos-x86_64.dmg`](https://github.com/ai-dashboad/opencli/releases/latest/download/OpenCLI-macos-x86_64.dmg)(Intel)를 내려받아
응용 프로그램 폴더로 끌어다 놓습니다.

**이 빌드에는 Apple 인증서가 없습니다.** 처음 실행할 때만 둘 중 하나가 필요합니다:

```shell
xattr -dr com.apple.quarantine /Applications/OpenCLI.app
```

또는 앱을 오른쪽 클릭하고 **열기** 를 선택하세요. **한 번만** 하면 됩니다.

</TabItem>
<TabItem value="windows" label="Windows">

[`OpenCLI-windows-x86_64-setup.exe`](https://github.com/ai-dashboad/opencli/releases/latest/download/OpenCLI-windows-x86_64-setup.exe)
를 내려받아 실행합니다.

**서명이 없어 SmartScreen이 파란 창을 띄웁니다.** **추가 정보** 를 누르고
**실행** 을 선택하세요.

</TabItem>
<TabItem value="linux" label="Linux">

[`OpenCLI-linux-x86_64.AppImage`](https://github.com/ai-dashboad/opencli/releases/latest/download/OpenCLI-linux-x86_64.AppImage)
를 내려받아 실행 권한을 주고 실행합니다:

```shell
chmod +x OpenCLI-linux-x86_64.AppImage
./OpenCLI-linux-x86_64.AppImage
```

</TabItem>
<TabItem value="cli" label="터미널">

```shell
curl -fsSL https://opencli.ai/install.sh | sh
```

**플랫폼을 알아내** 맞는 빌드를 받아 `opencli` 를 `/usr/local/bin` 에 둡니다 ——
거기에 쓸 수 없으면 `~/.local/bin` 에 둡니다.

</TabItem>
<TabItem value="source" label="소스에서">

최근 버전의 Rust 툴체인이 필요합니다:

```shell
git clone https://github.com/ai-dashboad/opencli.git
cd opencli/opencli-rs
cargo build --release -p opencli-cli --bin opencli
```

</TabItem>
</Tabs>

**모델은 들어 있지 않습니다.** [하나를 가리켜 주세요](/getting-started/point-at-a-model) ——
로컬 Ollama, 당신의 서버, 아니면 [마흔 곳 남짓한 공급자](/getting-started/providers) 중 하나.
**그중 몇 곳은 무료 사용량을 줍니다.**

## 하룻밤을 쏟기 전에 알아 둘 만한 두 가지

**작은 로컬 모델은 프런티어 모델만큼 이 일을 잘하지 못합니다.** 화면은 같아도 추론은 같지 않습니다. 그리고 **도구를 부르지 않는 모델은 이 일을 아예 못 합니다** —— 대화만 합니다. 마음을 정하기 전에 [시험해 보세요](/reference/checking-a-model).

**에이전트의 샌드박스는 작업 디렉터리 안이라면 어디에나 쓸 수 있습니다.** 그 디렉터리가 바뀔 수 있는 범위의 전부입니다. **대화가 홈 폴더가 아니라 작업공간에서 열리는 이유가 그것입니다.**
