# 로드맵

**아는 것을 정직한 이름표를 달아서.** **여기에 날짜가 붙은 약속은 하나도 없습니다** ——
**작은 프로젝트이고, 지키지 못할 날짜는 날짜가 없는 것보다 값어치가 없기 때문입니다.**

## 지금 하고 있는 것

**코드 서명.** 데스크톱 빌드에는 Apple이나 Microsoft 인증서가 없고,
**그것이 제품에서 가장 거친 모서리**입니다: **갓 내려받은 것을 처음 열면,
아무 문제도 없는데 문제가 있다고 알려 줍니다.** **해마다 돈이 들고,
그것이 아직 이뤄지지 않은 유일한 이유입니다.**

**공급자 카탈로그.** 지금 공급자를 설정한다는 건 **직접 찾아봐야 하는 `base_url` 을 쓰는
일**입니다. **마흔 곳을 검증해 두었습니다 —— 그 목록은 앱 안에 있어야 하고**,
고르는 건 클릭 한 번, 그다음 키를 붙여 넣기여야 합니다.

**화면의 짜임새를 지금에 맞추기.** 패널은 **일이 아니라 부품으로 이름 붙어 있습니다** ——
artifacts, dispatch, scheduled. **그중 셋은 같은 대기열로 흘려보내면서 셋의 동등한 것처럼
놓여 있습니다.**

## 알고 있는 빈틈, 아직 시작 안 함

**오른쪽에서 왼쪽 배치.** 아랍어, 히브리어, 페르시아어는 **오늘도 번역 파일로 넣을 수
있지만 페이지는 여전히 왼쪽에서 오른쪽으로 놓입니다.** **그건 스타일시트를 고치는 일입니다.**

**흐름 캔버스.** 봇, 당번, 인계는 **이미 하나의 그래프를 이룹니다** ——
**그 데이터는 디스크에 있습니다** —— **그리고 그것을 볼 방법이 어디에도 없습니다.**
**지금 사슬 하나는 한 줄의 글자입니다.**

**화이트 라벨.** 브랜딩은 컴파일에 박혀 있습니다.

**한 줄보다 많은 모델 호환 표.** **이건 누구나 할 수 있는 가장 쓸모 있는 기여**이고,
**아무 허가도 필요 없습니다**: [모델을 시험하고](/reference/checking-a-model)
풀 리퀘스트를 여세요.

## 일부러 계획에 없는 것

**다중 사용자 서비스.** **게이트웨이는 설계상 1인용입니다.**
**당신의 파일을 읽고 당신 기계에서 명령을 실행하는 에이전트는, 계정을 붙인다고
멀티테넌트 서비스가 되지 않습니다.** **보안 모델이 완전히 다른 별개의 제품이 됩니다.**

**호스팅 버전.** **당신이 고른 모델 공급자 말고는 당신 데이터가 갈 곳이 없습니다.**

**우리 자신의 모델.** **이건 모델을 담고 있지 않고, 추론이 어디서 오는지에 대해 입장을
갖지 않습니다.** **그게 이것의 요점입니다.**

## 이 목록은 어떻게 바뀌는가

**이건 저장소 안의 파일**이고, 뭔가 움직이면 고쳐집니다.
**두 번째 절에 당신이 필요로 하고 실제로 쓸 것이 있다면
[그렇다고 말해 주세요](https://github.com/ai-dashboad/opencli/issues)** ——
**누군가 기다리는 빈틈은, 아무도 물어본 적 없는 빈틈과는 다른 것입니다.**
