# 사람들이 실제로 묻는 것

## 제 데이터가 어딘가로 보내지나요?

**당신이 설정한 엔드포인트로, 그 밖에는 아무 데도.** **중간에 우리 게이트웨이는
없고**, 텔레메트리 계정도 없으며, **바이너리에 박아 넣은 키도 없습니다.**

그 엔드포인트가 당신 기계의 모델이라면 **아무것도 기계 밖으로 나가지 않습니다.**

## 오프라인에서 되나요?

**네, 로컬 모델이라면.** 데스크톱 앱은 자기 업데이트를 확인하고 Models 패널은
인기 모델 목록을 받아 옵니다 —— **둘 다 네트워크가 없으면 조용히 실패하고**,
**둘 다 대화하는 데 필요하지 않습니다.**

## API 키가 필요한가요?

**모델을 로컬로 돌린다면 아닙니다.** Ollama, LM Studio, llama.cpp 같은 것들은
아무것도 요구하지 않습니다. 호스팅 공급자는 자기 키가 필요하고, **설정 파일과 떨어져
보관되며 다시는 보이지 않습니다.**

## 어떤 모델을 써야 하나요?

**당신 기계가 올릴 수 있는 것**. 다만 **양보할 수 없는 조건 하나**:
**도구를 부를 수 있어야 합니다.** 그러지 못하는 모델은 여기서 **대화에만 머뭅니다.**

[모델 시험하기](/reference/checking-a-model)는 **5분짜리 검사**로 이 물음에 답합니다.
거기 있는 표가 짧은 이유는 **돌려 본 것만 담기 때문**입니다.

## 왜 Claude Code / Codex 보다 못하죠?

**노트북에 맞게 양자화된 27B 모델은 GPT-5가 아니기 때문**입니다.
**화면은 같아도 추론은 같지 않습니다.**

**이 프로젝트가 바꾸는 것은 닿는 범위** —— **당신이 가진 모델을 애초에 이렇게 쓸 수
있는가** —— 이지, **얼마나 똑똑한가**가 아닙니다.

## GPT-5나 Claude를 쓸 수 있나요?

**네.** OpenAI나 Anthropic을 다른 공급자처럼 설정하세요.
**제품 안에 어느 쪽을 더 좋아하는 구석은 없습니다.**

## 대화는 어디서 시작하나요?

`~/.opencli/workspace` 에서. 어떤 부서에 속한 대화라면 그 부서의 디렉터리에서.

**예전에는 홈 디렉터리였습니다. 이제는 아닙니다.** **샌드박스의 쓰기 가능한 뿌리가
바로 작업 디렉터리이기 때문**입니다 ——
[샌드박스와 승인](/configuration/sandbox-and-approvals)을 보세요.

## 한 설치를 여러 사람이 쓸 수 있나요?

**아니요.** 게이트웨이는 **설계상 1인용**이고, **자기 소스에 그렇게 적혀 있습니다.**
**각자 자기 복사본을 돌립니다.** 그 뒤에 **공용 모델 서버**를 두는 것이 보통의 배치입니다.

## 노트북이 잠든 사이에 예약된 일이 도나요?

**아니요.** 예약 작업과 당번은 **OpenCLI가 열려 있는 동안에만** 돕니다.
**이건 서버가 아니라 로컬 에이전트이기 때문**입니다. 잠든 기계에서 반드시 터져야 하는
일은 `cron`, `launchd`, 작업 스케줄러의 몫입니다.

## Open WebUI나 Jan과 뭐가 다른가요?

**그쪽은 로컬 모델을 위한 채팅 화면이고, 좋은 것들입니다.**
**이쪽은 에이전트입니다**: 당신의 파일을 읽고 고치고, 명령을 실행하고,
**백그라운드에서 계속 일합니다.** **하는 일이 달라서 둘 다 돌리지 않을 이유가 없습니다.**

## 갈라져 나온 Codex와는 뭐가 다른가요?

**Codex는 OpenAI의 모델을 위해 만들어졌습니다.** 부서, 봇, 당번, 백그라운드 실행,
봇 사이의 인계, 기본 제공 흐름, 그리고 열 가지 화면 언어는 **분기 이쪽에서 나온
것들**입니다 —— **모델이 작을 때 무엇이 깨지는가에 대한 상당한 작업과 함께.**

## 왜 「앱이 손상되었다 / 확인할 수 없다」고 나오나요?

**빌드에 Apple이나 Microsoft 인증서가 없기 때문**입니다 —— **인증서는 해마다 돈이 들고,
이 프로젝트는 그 돈을 쓰지 않았습니다.** [설치](/getting-started/install)에
**무엇을 눌러야 하는지** 정확히 적혀 있습니다.

## 이름을 바꿀 수 있나요?

**아직은 못 합니다.** 브랜딩은 컴파일에 박혀 있습니다.

## 뭔가 고장 났습니다. 어디를 봐야 하나요?

[문제 해결](/help/troubleshooting), 다음으로 `~/.opencli/log` 의 로그,
그다음 [이슈](https://github.com/ai-dashboad/opencli/issues).
