Press kit

Everything needed to write about OpenCLI without asking us for it. All of it is free to use, and none of it needs permission.

In one sentence

OpenCLI is an agent — a terminal program, a desktop app and a local web UI — for any model that answers the OpenAI API, including one running on your own machine.

In a paragraph

Claude has Claude Code. OpenAI has Codex. The open models most people can actually run — Qwen, DeepSeek, GLM, Llama, Mistral — have none. OpenCLI is theirs. It reads files, runs commands and edits work, asks before it does anything it is not sure about, and keeps going in the background. It ships with nine departments of sample data, so the first run does something rather than explaining that there is nothing to do. It is Apache-2.0, it has no hosted service, and it sends your prompts to the endpoint you configured and nowhere else.

What it is not

It is not a chat window for local models — Ollama, LM Studio and Jan already do that well. It is not faster or smarter than a frontier model; a small local model is worse at this work and the site says so. What it changes is reach: whether the model you already have can be used this way at all.
